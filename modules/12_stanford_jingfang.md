## 一、斯坦福大学演讲：从感冒一路治到癌症

### 1.1 核心思想

经方如清垃圾——感冒如垃圾招蚊蝇，西医杀蚊（抗病毒），中医清垃圾（排病毒）。掌握桂枝汤就等于掌握了60%的经方。

### 1.2 桂枝汤为群方之祖

桂枝（阳·动脉）+ 白芍（阴·静脉）等量→动静脉等长平衡血流。炙甘草缓心跳防悸。生姜红枣补胃肠津液。

### 1.3 桂枝汤类方体系

| 方剂 | 适应症 |
|------|--------|
| 倍白芍→小建中汤 | 腹痛挑食、静脉曲张 |
| 加葛根 | 面部中风 |
| 麻黄汤 | 无汗恶寒伤寒 |
| 葛根汤 | 项背强几几温病 |
| 桂枝麻黄各半汤 | 寒热夹杂 |
| 大青龙（表寒里热）/小青龙（表寒里寒） | 时疫 |

### 1.4 诊断以触诊为准

- 摸手掌手背温差、额头凉否判正常
- 循经穴压痛点：胆结石（阳陵泉下一寸）、肾结石（太溪穴周）

### 1.5 四逆散 ≠ 四逆汤

- 四逆散（柴芩枳草）：治阳证四逆剧痛
- 四逆汤（生附干姜炙草）：治阴证四逆回阳救逆

### 1.6 结石专方

- 胆结石→四逆散+五倍子海金沙，急症喝米醋
- 肾结石→猪苓汤（滑石阿胶等），无痛排石，禁甘草

### 1.7 关键临床案例

| 案例 | 核心 |
|------|------|
| 老父"中风"实为麻黄汤证 | 打寒战脉浮紧→麻黄汤一付，次日晨练 |

| H1N1时疫 | 大青龙/小青龙证，抗药性超级病毒仍可用 |
| 肾结石 | 猪苓汤无痛排石，有患者排出象棋大石不痛 |

## 二、经方的妙用讲座（2009年12月）

### 2.1 经方定义

经方出自《伤寒论》《金匮要略》，以《黄帝内经》为生理学、《神农本草经》为药物学，经方就是"绝对处方"，是最标准最有效的方子。

### 2.2 经方特点

1. **药简力专**：每味药都不可缺少，多一味少一味都不行
2. **剂量精准**：比例最重要，非单纯提高剂量
3. **辨证论治**：同样的病不同的人用不同的方
4. **一剂知二剂已**：效果好得出奇

### 2.3 经方与现代医学对比

| 方面 | 经方医学 | 现代医学 |
|------|----------|----------|
| 理念 | 扶正祛邪，调整阴阳 | 对抗病原，杀死细菌 |
| 方法 | 汗吐下和温清消补 | 抗生素、激素、手术 |
| 副作用 | 几乎没有 | 大量副作用 |
| 费用 | 便宜 | 昂贵 |

### 2.4 经方治癌思路

**不杀癌细胞，改变癌细胞生存环境。** 把冷水（癌细胞喜欢）变成热水（癌细胞无法生存）。癌细胞怕热。

### 2.5 学好经方三步走

1. 熟读伤寒金匮原文
2. 理解每味药的性味归经
3. 多临床实践，积累经验

## 四、人纪归纳总结

### 4.1 望诊总结

1. **面色**：青主肝/痛/寒；赤主心/热；黄主脾/湿；白主肺/虚/寒；黑主肾/寒/水/痛
2. **眼神**：有神则生，无神则死
3. **舌诊**：舌质淡白=血虚/寒；舌红=热；舌紫暗=瘀血；舌胖大=湿
4. **体型**：胖人多痰湿，瘦人多火
5. **步态**：步履蹒跚=肾虚；走路摇摆=风证

### 4.2 诊病十问

倪师强调：**病是问出来的。**

1. 问寒热（怕冷怕热）
2. 问汗（有汗无汗，何时出汗）
3. 问头身（头身何处不舒服）
4. 问便（大小便情况）
5. 问饮食（胃口、口渴、喜冷喜热）
6. 问胸腹（胸腹有无胀痛）
7. 问听力/视力
8. 问饮水（口渴与喝水比例）
9. 问旧病（既往病史）
10. 问病因（什么原因引起的）

### 4.3 常用压痛点总结

### 4.4 总结医案中加减方法

1. **随证加减，不可乱加**：证变才加减，证不变方不变
2. **寒热并用原则**：上热下寒→石膏配生附子；真寒假热→生附子配少量石膏
3. **攻补兼施**：虚实夹杂时攻补并用
4. **急则治标，缓则治本**：先解决最紧急的症状
5. **经方优先，成方不拆**：能用经方原方就不要拆散

## 五、倪师核心学术体系总结

### 四大支柱

1. **阴阳辩证法**：手诊秒断阴阳。阳不入阴形成阴实=所有癌症的共同病机
2. **奶水=月经理论**：七种癌症同一根源——心脏受伤→奶水逆流
3. **扶阳即防癌**：唯一预防癌症的方法是扶阳。生附子/生硫黄破阴实
4. **经方药简力专**：桂枝汤为60%经方之基。精准剂量+对证=重病一剂知

### 倪师最强调的生活原则

1. 保持手脚温热（阳气充足）
2. 子时前入睡（养肝血）
3. 少食生冷（护脾胃阳气）
4. 心情愉快（喜能胜忧，防癌第一）
5. 适度运动（旋转性运动，清气实四肢）
