## 二、经方的运用与阴阳辩证法的关系

### 2.1 经方核心原则——药简力专

药物尽量简化，越简化力量越专一。如月经逆流（逆经），仅用桂枝汤加郁金一味即可，不须多药堆砌。

### 2.2 阴阳辩证法

阳是看不到但存在的力量（如讲话铿锵有力），阴是看得到的形（头发、皮肤）。阳不等于"热"，阴不等于"寒"。阴阳互抱，"阴平阳秘，阳主阴从"为常态。

### 2.3 疾病传变三级跳

阴虚（脏腑阴液不足，病人会自救想食）→ 阳虚（气血循环力量不够，疲劳）→ 阴实（脏内长东西，积而不移，死症前兆）。扶阳阻断此传变链。

### 2.4 阴实形成机理

阳入阴受阻，阳不能入阴形成阴实。如乳癌局部热（阳阻在外）+ 周边凉（阴实在内）。肺癌24小时持续痛且上热下冷。

### 2.5 唯一防癌法——扶阳

- 运动需旋转性（清气实四肢），直线运动只练肌肉
- 素食淡味渗泄属阳
- 七分饱"虚胜于实"，过度营养反而成阴实

### 2.6 正常人六标准（诊断与停药依据）

1. 通宵睡眠（阳能入阴）
2. 正常胃口
3. 口渴与流汗保持正常比例
4. 大小便正常（小肠温度够则脚热）
5. 晨6点醒即起，下午精神好
6. 常年头面冷、手脚温热

### 2.7 十二时辰气血流注诊断法

- 肺寅时（3-5点）醒→肺癌前兆
- 肝丑时（1-3点）醒→肝癌早期
- 提前1-2年即可预警

### 2.8 阴阳药物区分法则

- 辛甘发散为阳（桂枝），酸苦涌泄为阴（白芍）
- 淡味渗泄为阳（莲子、白术），咸味涌泄为阴（芒硝）
- 白为阳黑为阴（石膏白为阳药，熟地黑为阴药）
- 直观不须背书

### 2.9 急下存阴

元气半虚攻补兼施，极虚用轻剂淡渗（白术仅2钱可日排尿2500-3000ml排腹水）。

## 三、美国临床案例

### 3.1 血癌案例（75岁白人男性）

**辨证**：抗生素伤心脏→结代脉；第六椎压痛；24小时盗汗表阳虚；脸上无胡子。

**用药**：炙甘草汤（炙甘草一两）+ 炮附子固表阳 + 龙骨牡蛎镇惊 + 白术茯苓健脾胃。

**关键区分**：炮附子"固阳"（保住现有阳气），生附子/生硫黄"起阳"（从50分回100分）。

**结果**：一周WB从39降至28，伤口自愈。

### 3.2 血癌+淋巴癌+乳癌（73岁白人男性）

**辨证**：乳癌开刀化疗后转移；脚冷、里寒、寒热并结、便秘、失眠。四逆汤证+黄连阿胶汤证。

**用药**：生附子2钱 + 当归四逆汤 + 防己茯苓 + 黄连阿胶 + 瓦楞子牡蛎攻坚。

**关键原则**：手脚温热=全身水气化=无冷水停积=肿瘤无生长环境。

### 3.3 红斑狼疮案例（黑人女性，50岁）

**辨证**：
- 病因：42岁离婚情绪创伤→三天不讲话→月经停→奶水逆流入心→第五椎压痛
- 里寒重（不渴），上焦虚热（胃口过强），真寒假热
- 肾阳不足→小便失禁
- 八年无月经，胸部胀满，一挤奶水可喷墙上

**用药**：
- 生附子五钱 + 细辛两钱（去里寒主力）
- 石膏六两 + 知母五钱（胃口过强，阳明经热）
- 防己泽泻茯苓（三焦利水，排奶水）
- 柴胡郁金龙胆草（防奶水入肝）
- 黄精 + 桑螵蛸（补肾）
- 第三阶段：桔梗甘草汤（伏饮被生附子逼出，白痰转黄=由寒转热=好现象）

**结果**：治疗两月，病人感觉到"心脏里面奶水流回乳房"，西医检查"你没有红斑狼疮了"。

### 3.4 脑瘤病例

**病例1**：51岁白人兽医，左脑脑瘤术后复发
- 辨证：左耳失聪、左手冰冷、小便无力、便秘、脸色青黑、手掌暗红
- 用药：生附子5钱 + 生硫黄 + 生半夏 + 阳起石（回阳攻坚逐脑积水）
- 节气用药：10月至3月（冬主收藏）维持原量；4月后加量
- 结果：MRI肿瘤缩小→消失

**病例2**：约旦30余岁男性，淋巴癌转移脑瘤
- 辨证：13次放疗+类固醇→下半身无知觉、性功能丧失、平衡丧失
- 用药：生附子4钱 + 生硫黄3钱（攻三焦阴实）+ 生半夏逐脑积水
- 中间并发肺炎救急：甘草干姜汤+炮附子一两+小建中意+西洋参
- 结果：次年6月停药，MRI无癌，正常生活

### 3.5 尿毒症案例

**辨证**：
- 头晕（冷水积横膈膜）+ 恶心（冷水积胃）
- 双足寒冰、小便无便意、便秘（寒实）
- 肾衰竭原理：肾阳没了→水不气化→累积冷水→血压升高

**用药（当归四逆汤加减成方）**：
- 生附子三钱 + 干姜两钱（四逆汤意：壮心阳）
- 炮附子三钱（固肾阳）
- 白术茯苓（健脾开胃）
- 当归四逆汤（木通当归细辛→治手脚冰冷）
- 未洗肾时加黄连黄芩解尿毒

**好转标志**：有汗流出=心脏功能恢复；月经恢复=心脏功能恢复。最终停洗肾。

### 3.6 乳癌案例

**案例1（哈尔滨李小姐）**：
- 左乳硬块坚硬如石、乳头凹陷、极渴喜冰水→白虎汤证
- 石膏六两 + 知母五钱 + 四物汤加炒麦芽 + 牡蛎龙骨 + 防己茯苓
- 第五天"坚硬如铁块变棉花"，一周全消

**案例2（台湾詹桂香）**：
- 30年乳癌史，二尖瓣三尖瓣闭锁不全
- 黄连阿胶汤 + 酸枣仁汤 + 栀子豆豉汤（三方合治失眠）
- 栝蒌实枳实薤白（治瓣膜闭锁不全）
- 结果：2008年回台检查"完全没有乳癌"

### 3.7 肝癌案例

**案例1**（西雅图男性）：
- B肝→干安能→肝硬化→肝癌
- 生附子 + 生硫黄（破阴实主力）+ 柴胡茜草炙鳖甲（清肝活血软坚）
- 四神汤当主食（甘淡渗利预防腹水）
- 一年多无腹水，肿瘤缩小

**案例2**（31岁中国男性）：
- 左肝切除+右肝栓塞，彻夜不眠，夜间身热（阳不入阴）
- 四逆汤 + 小建中汤 + 柴胡茜草炙鳖甲 + 生硫黄三钱
- 7个月后全部恢复，至今存活
