## 一、前言·伤寒论框架

"伤寒"广义为"伤于寒"（涵盖中风、伤寒、湿温、热病、温病五种）。外感病分时疫（男女老少同症）与普通伤寒（依正气节气得病）。张仲景以内经热论六经辨证整合经典汤方，形成"绝对处方"体系。一天六气循环：厥阴→少阴→太阴→少阳→阳明→太阳，顺行=健康，逆行=病态。太阳篇占全书60%以上。

## 二、经方剂量与桂枝汤精义

### 2.1 剂量决定生死

- 瘦小者一两起步，壮者三五钱。剂量错则无效
- 白芍重用到一两以上治静脉曲张

### 2.2 桂枝汤方义

桂枝（阳·动脉）+ 白芍（阴·静脉）等量→平衡动静脉血流。单用二者会速动悸→加炙甘草缓之。生姜入胃、大枣补津液防肠胃干瘪。去姜枣草则病人动悸汗多食不下。

### 2.3 关键加减

| 症状 | 加减 |
|------|------|
| 腹痛 | 白芍加倍（小建中加饴糖） |
| 胸痛 | 桂枝加倍 |
| 手冷脚热 | 加重桂枝减白芍 |
| 心悸 | 桂枝甘草汤等量加重 |
| 脉结代 | 炙甘草用至一两 |

### 2.4 阴阳药物直观判断

白为阳（石膏），黑为阴（熟地）。辛甘发散为阳，酸苦涌泄为阴。

### 2.5 急下存阴与癌症时机

丑时（1-3点）准时醒+盗汗=阴实未形，宜急下存阴；晚期阴阳两隔不可攻。

### 关键案例

- 儿童腹痛挑食：小建中汤（白芍六钱+饴糖）→即思食
- 太太20年静脉曲张：白芍一两+炙甘草一两+炮附子三钱→服药后眩晕（瞑眩反应），次日静脉瘤消九成
- 肝癌腹水：四神汤/平胃散（无甘草）淡渗排水，加生附子回阳

## 三、风湿与类风湿关节炎经方

### 3.1 甘草附子汤（基础方）

桂枝祛风 + 炮附子去寒 + 白术去湿 + 炙甘草缓急。治痛风、一般风湿、晚上抽筋。抽筋厉害：炙甘草加至一两。

### 3.2 桂枝芍药知母汤（膝盖专方）

甘附汤药力分散全身→加麻黄宣肺把药力压到下肢膝盖。加知母除肺湿，加防风止痛，加麦冬补肺津。治膝盖固定痛、关节肿痛。

### 3.3 乌头桂枝汤（类风湿专方，唯一）

乌头一两+桂枝汤。手变形关节剧痛（巫婆手）。安全制法：乌头三碗煮一碗去渣+一碗蜂蜜炖成乌头蜜→取一匙乌头蜜+一碗桂枝汤搅拌服，已无毒。热透手指，关节嘎吱变回。

### 3.4 炮附子 vs 生附子

- **炮附子**：固表止虚汗（桂枝汤加炮附）
- **生附子**：去里寒（脸色白、掌冷、冻疮、喜热饮）

## 四、消化系统堵塞辨证

从食道到肛门口，各部位堵塞对应不同经方。

| 部位 | 辨证要点 | 经方 |
|------|----------|------|
| 胃宿食 | 朝食暮吐，消化不好恶心 | 大黄甘草汤（大黄2:甘草1） |
| 十二指肠 | 心下痞硬，拒按，舌苔黄 | 调胃承气汤（+芒硝攻坚） |
| 小肠·脾约证 | 排便如羊大便一粒粒 | 麻子仁丸 |
| 小肠·小承气证 | 便秘无便，排气极多如机关枪 | 小承气汤 |
| 大肠头/阑尾 | 盲肠破被膜包，右下腹痛 | 薏附子败酱草汤 |
| 阑尾炎 | 足三里下两寸阑尾点压痛 | 大黄牡丹皮汤 |
| 大肠全堵 | 腹梆硬，小便深黄 | 大承气汤 |
| 肛门口痔疮 | 便秘+痔疮裂痛 | 大承气汤+当归槐花 |

### 药效判断标杆

- 表证（感冒）：经方后**次日中午胃口大开**=胃气复、病愈
- 内科/癌症重症：服药后**半夜12-2点想吃东西**=阳入阴、病情好转

### 核心法则

"唐荣川：治肝先治大肠"——大柴胡汤（小柴胡去半夏加枳实白芍大黄）

## 五、阴阳诊断法与奶水即月经理论

### 5.1 阴阳手诊法

- 手掌为阴（应热），手背为阳（应凉），额头应凉（法天）
- 正常人：手掌热+手背凉+额头凉+手脚温热
- 指头冷=阳不足→桂枝甘草汤（桂枝五钱炙甘草五钱）
- 手掌暗红→肝实证（肝癌血大量入心）；转粉红→阴实退
- 手掌粉红（白多红少）为正常制衡——肺白色、心赤色，肺大心小方为平人

### 5.2 心与肺制衡

心脏如汽车引擎，肺如水箱（恒温）。唇干燥渴→肺津亏→白虎汤。瓣膜闭锁不全→湿停心包与心间→栝蒌实枳实薤白。

### 5.3 奶水=月经理论（七个证据）

1. 每月经前涨奶
2. 结扎妇无卵仍月经
3. 哺乳期无月经
4. 断奶后月经来
5. 四物汤+炒麦芽可退奶化月经
6. 奶水逆流七癌同源
7. 心脏管理奶水下行

### 5.4 癌症诊断

- 癌处烫（阳不入阴，阴实阻阳）
- 几乎百分百盗汗
- 第五椎压痛=红斑狼疮；第六椎压痛=血癌；第三椎压痛=肺癌

### 5.5 更年期防肺癌

停经后宁可下利勿便秘（防奶水逆肺→第三椎痛→寅时醒）。

## 六、乳癌、血癌、肺癌病因与阴阳转化

### 6.1 三大癌症的中医病因链

**乳癌外因**：维他命C片剂（非天然）、抗生素、止痛药、牛奶→伤心脏。**内因**：情志内伤。

**血癌病因**：男人精子残渣沿任脉上注口角→心脏伤→残渣反逆入督脉第六椎→血癌。好转标志：开始每日刮胡子。

**肺癌警惕**：忧能伤肺。红丝灌睛=极度忧郁。喜能胜忧（火克金）。

### 6.2 治癌三法则

1. 去冷水：排冷水变热水，改环境饿死癌细胞
2. 断营养：阻绝人工维他命、钙片等
3. 水为阳、食物为阴，阴阳兼顾，气化全身水

### 6.3 阴阳转化

- 少阴寒实（脉微细舌苔白厚润）vs 阳明热实（脉宏大舌苔黄干至黑）
- 男怕脚肿（阳绝），女怕头肿（阳绝）

## 七、阴阳诊断实操与尿毒症、手抖案例

### 7.1 阴阳秒诊法

手掌（阴）应热，手背（阳）应凉，赤白肉际为阴阳交界。手掌冷至根=阴寒体质；手掌热+额头烫=阴中阳外越（肺癌）。用药后掌渐热额渐凉→好转。

### 7.2 尿毒症急救

肾不纳水（真武汤）+ 横膈鸣眩（五苓散）复方。应急时去炙甘草（防蓄水），干姜+生附强心。脸黑退、血色回、小便有便意、出汗恢复=心脏功能回。

### 7.3 手抖案例（32岁女）

情伤手抖（心颤），寒缩（热纵寒缩）全身硬。当归四逆汤+桂枝芍药知母汤复方：生附子+龙骨牡蛎+炮附子+麻黄+防己知母。

### 7.4 用药总则

- 炮附配生姜，生附配干姜（急救）
- 大黄泡水取气治角膜炎，煮取味下泄
- 细辛用根避马兜铃酸
- 生附去里寒，炮附固表
- 经方成方固定，时方单味可加

## 八、22岁SLE案例完整辨证

**辨证**：
- 三个月前与男友吵架→气机逆乱→心脏受伤
- 月经延迟=寒；里寒→想喝热饮、脸色苍白、手脚冷
- 奶水逆流入心→第五椎压痛（关键诊断点）
- 奶水随心脏喷射至手指末梢→关节游走痛
- 心阳空转摩擦生虚热→反复发烧（假烧）
- 脉数似热，但舌白喜热饮=里寒→舍脉取症

**用药**：
甘草附子汤（桂枝三钱 + 炮附子五钱 + 白术三钱 + 炙甘草五钱）+ 生附子三钱 + 干姜二钱 + 小建中汤意（白芍六钱 + 饴糖）+ 党参三钱 + 天花粉麦冬各三钱润津液。

**医嘱**：激素每礼拜减25%一个月停完；停全部维他命钙片；感冒找中医。预期一个月内痊愈。
