# 易筋经与五脏逼毒法（倪师人纪功法完整版）

> **来源**：《人纪-金匮要略》倪师讲课练功夫段落（源文件 2026-08-12 补齐）。
> **用途**：练功类问题（五脏逼毒法/文式易筋经/武式易筋经）、养生功法、倪师"运动观"（旋转行气、练功强身防病）。
> **体系关系**：倪师教两套易筋经——针灸课教**武式**（练气脉，让气脉游走全身，与十二经络奇经八脉相关）；金匮课教**文式**（练静、练力道，站姿不借外力，12 势）。练任何功夫前先做**五脏逼毒法**把内脏毒素排掉。

## 总则：练功次序与核心诀窍

```
五脏逼毒法（练功前先逼毒）→ 文式易筋经（练力道/静）→ 武式易筋经（练气脉）
```

- **练功时辰**：清晨起来练最好，面向正东方，瞪目看前方。
- **一松一紧**：文式易筋经下盘（肚脐以下）永远绷紧、坚如磐石，上半身放松；做动作时上半身慢慢绷紧，绷到极限再松开——**一松一紧算一下**，每势 49 下。
- **寸劲原理**：中国功夫在"寸"——放松，快打的那一刹那出力，一寸距离内发力（练武式转体、按蹻下按均用此理）。
- **练功好处**：外练筋骨皮防风寒入侵（八段锦/太极拳/易筋经同理）；练易筋经不得历节、不得骨节间病（寒湿在骨节）；小便不能喷射（小肠火不足）要练；运动以旋转为主（易筋经），直线劳动耗气。

## 一、五脏逼毒法（六字诀）

> 练任何功夫以前，把内脏毒素排掉。不用药物，用武术动作+发声。核心诀窍：**先吸气再吐气逼毒，最后吐完气没气时，提肛、全身压紧、用无声的力再逼 3-5 秒——真正逼毒就在最后那一下无声的逼**。若最后一步没做好，前面练半天等于没逼到毒。
> 练完会咳、吐、流泪、吐津液，都是正常（把痰浊逼出来）；若从头到尾没咳没吐没津液，要么身体很干净，要么动作没做对。

| 脏腑 | 声 | 动作要领 | 开窍配合 |
|------|-----|----------|----------|
| **肝** | 嘘 | 两手将肝区（右肋骨）轻轻压进去，嘴发"嘘"，声不可大 | 肝开窍于目→最后瞪目 |
| **心** | 呵 | 手盖住心脏，吸完气慢慢吐气发"呵" | 心开窍于舌→舌头伸在嘴中（不要吊死鬼式全伸） |
| **脾** | 呼 | 嘴巴变 O 字形，手按左肋下方 | 脾开窍于唇 |
| **肺** | 呬 | 手往上、脚踮起，牙齿合拢、舌头顶齿间，正面侧面皆可 | 最后没气时提肛踮脚再呬几秒 |
| **肾** | 吹 | 坐椅上或站立，后腰微拱、头往前，手按肾脏 | 命门热走督脉上头顶 |
| **三焦+心包** | 吸 | 与呬接近：手拉起慢慢往上顶、脚踮起，**断续地吸**（吸-吸-吸-吸），最后没气可吸时无声用力 | 水肿病人练完就小便或全身发汗（三焦被叫醒） |

> 六字当"阿弥陀佛"一样常练。三焦心包是脏腑间沟通管道（内分泌/淋巴），累积浊物（过胖/便秘/水肿）用"吸"逼。公园人多练"吸"很奇怪，躲角落或卧房练。

## 二、文式易筋经（12 势）

> **总诀窍**：站姿练、不借外力（勿举重，举重太过伤肾）；下盘（肚脐以下）所有动作都一样——打赤脚站在草地泥地（吸地气），五个脚趾像鸡爪抓地，屁股肚脐以下肌肉绷紧、自然提肛；上半身放松。握拳必须平（手背与小臂平，尺骨桡骨平行），否则打击会扭伤手腕。**文式有 12 个动作，每个动作 49 下，一气呵成练完功夫已很高。**
> 练时舌顶上颚、瞪目；练完精神极好（倪师：越练精神越好，五六十岁练体格会很好，头发黑跟练易筋经有关）。

| 势 | 名称/动作 | 要点 |
|----|-----------|------|
| **1** | 按蹻式（按跷） | 背挺直、眼睛瞪怒、舌顶上颚、牙齿咬紧，手在膝盖旁/大腿旁轻轻提起，下按一寸"寸劲"，像手按桌子要跳起来，49 下。练约 30 下开始出汗、背后是冰的（太阳寒水）——毛孔开、汗出、肠胃津液补回，不用跑步一练就出汗。去外感（风寒暑湿燥热刚进经络时发汗即去） |
| **2** | 练肺式（大拇指） | 大拇指属手太阴肺经（肺是呼吸力量，气动工具比喻），握拳拇指往上翘对裤缝，轻轻提起一寸，做 49 下。练肺气；第一个动作练心包（手指上翘处） |
| **3** | 握拳拉开式 | 两手握拳往两边拉、稍提上来，配合呼吸：松掉-吐气、吸气-握紧，握到水都进不去，49 下。开关节、清湿气 |
| **4** | 前扳式 | 站正面，握拳在肚脐前（不贴肚），出力时手往前扳，前扳牵动大肠经+肺经，吸气做 49 下 |
| **5** | 膻中式 | 手在胸口（正中间膻中穴），握拳不要碰到胸，沉肩（肩膀不提），下半身绷紧，49 下 |
| **6** | 正前方握拳 | 握拳正前方，手指头朝前，沉肩不出力，握 49 下；握到极限全身紧，松掉只有上半身松、下半身保持紧 |
| **7** | 侧拉弓身 | 脚手一起动，拳头抬起往侧面拉，上半身绷紧、脚和腰弓一下（防留饮） |
| **8** | 上仰握拳 | 手在上面，下半身绷紧、上半身握拳 49 下；阳在下焦收缩，借呼吸把阳逼上来、排身上饮 |
| **9-10** | 辘轳式 | 上半身转、下半身不动（下盘坚如磐石），握拳，紧到不能再紧再转上半身，转少许（寸劲），左一个右一个 |
| **11** | 后拉式（打躬） | 正面站立握拳，从后面拉，握拳慢慢往后拉、拉到不能再拉放松，吸气慢慢吐气（倪师讲课版）；附录标准版含鸣天鼓（掩耳弹枕 7 次）、弯腰卷脊、颈椎反翘 |
| **12** | 抱弓式 | 胸前握拳像张弓拉开来，做 49 下，舌顶上颚、瞪目；练胸阳。原理：下半身绷紧固阴、上半身练阳，一放松阴阳流行甚快 |

> **附**：源文件另收录《易筋经》标准十二式结构版（韦驮献杵/摘星换斗/倒拽九牛尾/出爪亮翅/九鬼拔马刀/三盘落地/青龙探爪/卧虎扑食/打躬式/掉尾式等，含"鸣天鼓"“左右摆尾"细节），为通行易筋经体系，可作参考（非倪师文式）。

## 三、武式易筋经

> **定位**：针灸课教，与十二经络、奇经八脉相关；练气脉、让气脉游走全身，与文式（练力道）相辅相成。武式练起来很费力——**每个动作练 1-2 次即可**（练 49 下会太耗体力昏迷过去）。
> **奇经八脉混入**：阳跷阴跷、阴维脉的拉法（脚弯起往外翻，身体像花一样往外张），弓字步越蹲越低拉筋，帮助阳跷阴跷筋脉松开、气血活络。

| 式 | 动作要点 |
|----|----------|
| **韦驮献杵式**（第一式，3 个动作） | 马步放松两手，吸气时很自然拉开，吐气背挺直；转身两脚内八，往外稍往上撑，吐气下来收工 |
| **拨云见日** | 手晃动，如拨开云见日 |
| **摘星换斗** | 心想天花板很高、把身体拉到最长，手上旋转，脚趾头翻过去 |
| **拔刀式**（九鬼拔马刀） | 心想背后长刀插鞘三尺拉不出来，用旋转动作；脚侧退成弓字步、身体弯下去碰脚，吸气吐气吐满回头再碰脚 |
| **青龙探爪** | 马步、全身放松、手握拳在腰际，龙爪在前，往上升左右走，体力好可来回几次；下弯时双膝保持笔直，量力而行 |
| **倒踩九牛尾** | 像甩手功但心法不同——旋转扭转你的筋，收上去旋转、下来也旋转，去和回都要出劲；心想后面九条牛扯出去，手旋转、肩膀放松、配合自然呼吸 |
| **出爪亮翅式**（震动） | 爪出来放松，震动从手到身上、眼睛、喉咙、额头、脸上的肉都跟着震动，频率从上身传到脚；排筋络血脉神经肌肉里的痰（帕金森/手抖类，藜芦甘草汤药已无，此功可代之） |
| **收势（最难）** | 手跟脚碰到且顶到不动、脚还要踮起来——从正面弯腰摸不到脚，反过来做：手先着地、脚慢慢走过去配合、再立起来，脚踮起、身体折起、阴阳相合。能做此动作的人身体无大问题；身体有问题或阴阳失衡者做不到。摆 1-2 分钟，能摆多久摆多久 |

## 四、常见问题速答

- **问：倪师自己练吗？** 平常不太敢练，因为越练精神越好（他睡 5 小时就够）；金匮最后一堂课说两年半没练，明天开始练（地纪要用体力）。
- **问：练功与治病的关系？** 外感风邪靠练功夫（外练筋骨皮）防风寒入侵；打坐练心（不受喜怒忧思悲恐影响）；练易筋经不得历节、不得寒湿骨节病；每周运动或练易筋经让汗出来（冷气间呆久者）；练易筋经（旋转行气）则不需壮阳药。
- **问：与八段锦/太极拳区别？** 目的相同（外练筋骨皮防病），文式练力道、武式练气脉，相辅相成。
- **问：能替代看医生吗？** 不能。功法是养生防病，有病仍须经方辨证治疗。
