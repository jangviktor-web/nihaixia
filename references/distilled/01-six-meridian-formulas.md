# 六经辨证诊断公式

> **来源**：倪海厦《伤寒论讲义》《黄帝内经讲义》
> **整理日期**：2026-06-08
> **用途**：临床快速辨证，一望而知病在何经

---

## 总纲

**倪海厦核心观点**：
- 伤寒论六经辨证源自《黄帝内经·热论篇》，张仲景将其系统化
- 六经是动态的**开阖枢**系统，不是静态的脏腑分类
- 阳气为生命根本："人身之阳气，犹如天与太阳"
- 胃气为生死关键："人绝水谷则死，脉无胃气亦死"
- 治病以阳药为主，不用补药——"阳一壮就把阴拉起来了"

**金匮要略定位**（倪海厦）：
- "金匮是延续伤寒论而来的，所有方子基础都在伤寒论"
- "诊断方式还是以阴阳表里虚实寒热八纲辨症为主，同症同治"
- "中医不立病名，只看症——同症同治，不受病名限制"
- "上工治未病，有症状就动手，不等病名确立"

### 伤寒论经方两大补虚方

| 方剂 | 类型 | 六经归属 | 适应症 |
|------|------|----------|--------|
| **小建中汤** | 表阳虚 | 太阳兼太阴 | 虚劳里急、手足烦热、腹中痛 |
| **炙甘草汤** | 里阴虚 | 少阴阴阳两虚 | 脉结代、心动悸 |

> **倪海厦铁律**：遇到桂枝汤证/麻黄汤证时，若兼表阳虚，先用小建中汤；遇到脉结代，先用炙甘草汤补足里阴，再治其他。

## 诊断公式一：太阳病

### 提纲

> **「太阳之为病，脉浮，头项强痛而恶寒。」**

### 辨证公式

```
IF 脉浮 + 头项强痛 + 恶寒
THEN → 太阳病
```

### 分型鉴别

| 分型 | 核心症状 | 脉象 | 治法 | 代表方 |
|------|----------|------|------|--------|
| **中风** | 发热 + 汗出 + 恶风 | 浮缓 | 解肌 | **桂枝汤** |
| **伤寒** | 发热 + 无汗 + 恶寒 + 体痛 | 浮紧 | 发汗 | **麻黄汤** |
| **温病** | 发热而渴 + 不恶寒 | 浮数 | 生津解表 | **桂枝加葛根汤** |

### 倪海厦辨证要点

- **有汗 vs 无汗**是太阳病第一鉴别点
  - 有汗 → 桂枝汤（解肌）
  - 无汗 → 麻黄汤（发汗）
- 脉浮紧 = 身体好，正气强
- 脉浮缓 = 身体素虚
- "桂枝汤本为解肌"——肌肉层面的病，皮肤毛孔没闭
- 麻黄汤证 = 寒束皮肤表面，毛孔闭塞

### 桂枝汤组成（调和阴阳第一方）

| 药物 | 剂量 | 作用 |
|------|------|------|
| 桂枝 | 三两 | 壮心阳，加速动脉血流出 |
| 芍药 | 三两 | 活血，加速静脉血回流 |
| 甘草（炙） | 二两 | 解百毒，调和药性 |
| 生姜 | 二两 | 发阳，刺激肠胃蠕动 |
| 大枣 | 十二枚 | 补肠胃津液 |

> 桂枝白芍等量 → 调阴阳；阳不足加重桂枝，阴不足加重白芍

### 麻黄汤组成

| 药物 | 剂量 | 作用 |
|------|------|------|
| 麻黄 | 三两 | 发汗解表，宣肺平喘 |
| 桂枝 | 二两 | 温经散寒，助麻黄发汗 |
| 杏仁 | 七十个 | 宣降肺气 |
| 甘草 | 一两 | 调和诸药 |

### 禁忌

- 酒客不可用桂枝汤（胃已被酒伤，红枣增湿增腻）
- 脉浮紧、无汗者不可用桂枝汤
- 有表证时**绝对不可攻里**（先解表再攻里）

## 诊断公式二：阳明病

### 提纲

> **「阳明之为病，胃家实是也。」**

### 辨证公式

```
IF 身热 + 汗自出 + 不恶寒反恶热 + 脉大
THEN → 阳明病
```

### 分型鉴别

| 分型 | 核心症状 | 病位 | 代表方 |
|------|----------|------|--------|
| **经热** | 大汗 + 大烦渴 + 脉洪大 | 血脉神经 | **白虎汤**（加人参） |
| **腑热** | 腹满 + 便秘 + 谵语 | 肠胃消化系统 | **承气汤类** |

### 倪海厦辨证要点

- **阳明无寒证，全是热证**
- 阳明居中土，万物所归，**无所复传**——病到阳明就停住
- 辨证口诀：
  - 舌苔黄燥 → 阳明
  - 大渴饮冷 → 阳明
  - 中脘痛而拒按 → 大便堵到
  - 阙上痛（印堂痛） → 燥气上冲
  - 正头顶痛 → 也是阳明
- 阳明病发时间：申时到戌时（黄昏）
- 若大便堵在盲肠处 → 右腿弓起方可入眠

### 白虎汤组成

| 药物 | 剂量 | 作用 |
|------|------|------|
| 石膏 | 一斤 | 清热 |
| 知母 | 六两 | 清热生津 |
| 甘草 | 二两 | 调和 |
| 粳米 | 六合 | 保胃气 |

> 加人参 → 防心脏衰弱，补助津液消耗

### 阳明腑实分层

| 层级 | 症状 | 方剂 |
|------|------|------|
| **轻证** | 腹微满 + 便秘 + 无谵语 | **调胃承气汤** |
| **中证** | 腹满痛 + 便秘 + 微烦 | **小承气汤** |
| **重证** | 腹满痛拒按 + 便秘 + 谵语 + 潮热 | **大承气汤** |

## 诊断公式三：少阳病

### 提纲

> **「少阳之为病，口苦，咽干，目眩也。」**

### 辨证公式

```
IF 口苦 + 咽干 + 目眩 + 往来寒热 + 胸胁苦满 + 呕
THEN → 少阳病
```

### 少阳三禁（铁律）

> **汗之则谵语，下之则悸而惊，吐之则烦而悸**
>
> 少阳病**只能和解**，不可汗、不可下、不可吐

### 倪海厦辨证要点

- 少阳 = 半表半里，在表之里、在里之外
- **少阳不可吐、不可下，只可和解**
- 胆汁回逆 → 口苦
- 血脉受邪津液不足 → 咽干
- 眼睛靠血滋润，血热 → 目眩
- **有呕就想到少阳**
- 脉弦 = 少阳证的特征脉
- 太阳表邪进入少阳时，第一个碰到胆

### 少阳四大主证

| 主证 | 病机 |
|------|------|
| 口苦 | 胆汁回逆上冲 |
| 咽干 | 津液不足 |
| 目眩 | 血热上扰 |
| 往来寒热 | 正邪交争，赢则热、输则冷 |

### 兼证

- 胸胁苦满
- 恶心呕吐
- 双耳无所闻
- 目赤

### 小柴胡汤组成

| 药物 | 剂量 | 作用 |
|------|------|------|
| 柴胡 | 半斤 | 入三焦淋巴系统，清热去寒 |
| 黄芩 | 三两 | 杀菌消炎 |
| 半夏 | 半升 | 去水止呕 |
| 人参 | 三两 | 固脾胃 |
| 甘草 | 三两 | 调和 |
| 生姜 | 三两 | 止呕 |
| 大枣 | 十二枚 | 补津液 |

> **但见一证便是，不必悉具**——口苦、咽干、目眩、往来寒热、胸胁苦满、呕，见一个就可用

## 诊断公式四：太阴病

### 提纲

> **「太阴之为病，腹满而吐，食不下；若下之，必胸下结硬，自利益甚，时腹自痛。」**

### 辨证公式

```
IF 腹满 + 呕吐 + 食不下 + 自利（大便溏湿） + 时腹自痛 + 不口渴
THEN → 太阴病
```

### 倪海厦辨证要点

- 太阴 = 脾脏，**阴之始**
- 脾湿盛 → 脾脏肿大 → 胃被挤压 → 食不下
- 津液累积太多 → 呕吐白色津液
- 下利是**湿的、溏的**（不是水泻）
- **不口渴** = 湿在中焦
- 手足自温 = 胃气外散到四肢
- 舌苔白厚、津液多
- 腹诊：拒按为实，喜按为虚
- **欲解时**：亥至丑时（半夜胃气复）

### 太阴 vs 阳明 鉴别

| 项目 | 太阴 | 阳明 |
|------|------|------|
| 寒热 | 寒 | 热 |
| 口渴 | 不渴 | 大渴 |
| 大便 | 溏湿 | 便秘 |
| 腹痛 | 喜按 | 拒按 |
| 舌苔 | 白厚 | 黄燥 |

### 代表方剂

| 方剂 | 适应症 |
|------|--------|
| **四逆辈** | 自利不渴，脏有寒，当温之 |
| **理中汤/理中丸** | 温中焦之寒，霍乱寒多不用水 |
| **小建中汤** | 表阳虚兼太阴脾虚，虚劳里急腹痛 |
| **桂枝加芍药汤** | 太阳误下后腹满时痛 |
| **苓桂术甘汤** | 太阳太阴合病，水停中焦，心动悸目眩 |

### 建中汤系列（金匮扩展）

| 方剂 | 组成 | 六经归属 | 辨证要点 |
|------|------|----------|----------|
| **小建中汤** | 桂枝三两、甘草二两、芍药六两、大枣十二枚、生姜三两、饴糖一升 | 太阳兼太阴 | 表阳虚，手足烦热（假热），腹中痛 |
| **黄芪建中汤** | 小建中汤+黄芪 | 太阳太阴气虚 | 右手脉弱，气虚明显 |
| **当归建中汤** | 小建中汤+当归 | 太阳太阴血虚 | 左手脉细小无力，血虚明显 |
| **大建中汤** | 蜀椒、干姜、人参、饴糖 | 太阴大寒 | 心胸中大寒痛，呕不能饮食 |

**倪海厦经验**：
- 小建中汤是**治肝补脾不二法门**——甘味调脾胃，防肝木克土
- 小建中汤是**增胖药**而非减肥药，健脾阳功能极强
- 小儿不爱吃饭、印堂青青（肠寒）→ 小建中汤
- 表阳虚专用方：桂枝汤证兼腹痛 → 先用小建中汤

### 苓桂术甘汤详解（太阳太阴合病水饮主方）

| 药物 | 剂量 | 作用 |
|------|------|------|
| 茯苓 | 三两 | 利水渗湿 |
| 桂枝 | 三两 | 行胃阳，壮心阳 |
| 白术 | 三两 | 健脾燥湿 |
| 甘草 | 二两 | 缓性，让药停在胃部 |

**主症**：心动悸、目晕眩、头昏——水停中焦胃部
**病因**：大渴猛灌水，水堵在胃里，胃阳被阻不能上到头面
**与肾气丸区分**：苓桂术甘汤治中膈积水（浅证），肾气丸治肾阳不足（深证）

## 诊断公式五：少阴病

### 提纲

> **「少阴之为病，脉微细，但欲寐也。」**

### 辨证公式

```
IF 脉微细 + 但欲寐（精神萎靡） + 恶寒蜷卧 + 手足逆冷
THEN → 少阴病
```

### 倪海厦辨证要点

- 少阴 = 心 + 肾，**阴之中**
- 微脉 = 气衰弱；细脉 = 血不够
- 但欲寐 = 少阴主证，精神萎靡，讲话有气无力
- **少阴病完全是又阴又寒**，内脏功能都停滞
- **绝对不可发汗**（发汗会亡阳），不可攻下
- 自利而渴者属少阴（寒在下焦，引水自救）
- 小便色白 = 下焦虚寒，不能气化
- **欲解时**：子至寅上

### 少阴病鉴别要点

| 症状 | 病机 |
|------|------|
| 脉微细 | 气血不足 |
| 但欲寐 | 精神萎靡 |
| 自利而渴 | 寒在下焦，引水自救 |
| 小便色白 | 下焦虚寒，不能气化 |
| 恶寒蜷卧 | 阳气不足 |
| 手足逆冷 | 阳气不达四末 |
| 咽痛 | 虚火上浮 |

### 少阴 vs 太阴 鉴别

| 项目 | 太阴 | 少阴 |
|------|------|------|
| 层次 | 阴之始 | 阴之中 |
| 脏腑 | 脾 | 心/肾 |
| 脉象 | 浮缓/弱 | 微细/沉 |
| 精神 | 正常 | 但欲寐 |
| 手足 | 自温 | 逆冷 |
| 口渴 | 不渴 | 渴（引水自救） |

### 代表方剂

| 方剂 | 适应症 |
|------|--------|
| **麻黄附子细辛汤** | 少阴始得之，反发热，脉沉（兼表证）。**少阴证主方** |
| **四逆汤** | 下利清谷，里寒外热，手足厥逆，脉微欲绝 |
| **真武汤** | 腹痛，小便不利，四肢沉重，有水气。用**炮附子+生姜** |
| **附子汤** | 身体痛，手足寒，骨节痛，脉沉 |
| **八味肾气丸** | 少阴病根本方——虚劳腰痛、小便不利、消渴（下消）、短气微饮 |
| **炙甘草汤** | 里阴虚——脉结代、心动悸 |

### 四逆汤组成

| 药物 | 剂量 | 作用 |
|------|------|------|
| 甘草 | 二两 | 补中缓急 |
| 干姜 | 一两半 | 温中散寒 |
| 附子 | 一枚（生用） | 回阳救逆 |

> 用**生附子**时配合**干姜**，用**炮附子**时配合**生姜**

### 真武汤组成

| 药物 | 剂量 | 作用 |
|------|------|------|
| 茯苓 | 三两 | 利水渗湿 |
| 芍药 | 三两 | 敛阴和营 |
| 生姜 | 三两 | 温散水气 |
| 白术 | 二两 | 健脾燥湿 |
| 附子 | 一枚（炮用） | 温肾回阳 |

> 真武汤用**炮附子+生姜**，与四逆汤的生附子+干姜不同

### 八味肾气丸详解（少阴病根本方）

| 药物 | 剂量 | 作用 |
|------|------|------|
| 干地黄 | 八两 | 补肾阴（最重） |
| 山药 | 四两 | 润脾脏津液 |
| 山茱萸 | 四两 | 补肝阴 |
| 泽泻 | 三两 | 利肾疏肝 |
| 丹皮 | 三两 | 活血化瘀 |
| 茯苓 | 三两 | 利湿 |
| 桂枝 | 一两 | 壮心阳，心肾相通 |
| 附子（炮） | 一枚 | 温补肾阳 |

**倪海厦经验**：
- 去掉桂枝附子 = **六味地黄丸**（补肾阴）
- 加桂枝附子 = **桂附八味丸**（补肾阳）
- **三补三泻**：补药剂量必须比泻药重，地黄最重（八）
- 纯阳虚（阴寒症状）→ 桂附八味丸；虚热（口燥咽干）→ 六味地黄丸
- 下消糖尿病（阳不举）→ 桂附八味丸为主加减

### 炙甘草汤详解（里阴虚专用方）

| 药物 | 剂量 | 作用 |
|------|------|------|
| 炙甘草 | 四两 | 补中气 |
| 生姜 | 三两 | 温中 |
| 人参 | 二两 | 补津液 |
| 生地黄 | 一斤 | 滋阴补血（最重） |
| 桂枝 | 三两 | 壮心阳 |
| 阿胶 | 二两 | 补血 |
| 麦门冬 | 半升 | 润肺 |
| 麻子仁 | 半升 | 润肠 |
| 大枣 | 三十枚 | 补津液 |

**倪海厦铁律**：脉结代时，无论什么病症，先用炙甘草汤补足里阴，等脉恢复正常再治其他。

## 诊断公式六：厥阴病

### 提纲

> **「厥阴之为病，消渴，气上撞心，心中疼热，饥而不欲食，食则吐蛔，下之，利不止。」**

### 辨证公式

```
IF 消渴 + 气上撞心 + 心中疼热（胃脘灼热） + 饥而不欲食 + 下利 + 手足厥逆 + 寒热错杂
THEN → 厥阴病
```

### 倪海厦辨证要点

- 厥阴 = 肝 + 心包，**阴之尽**，人体最后一道关卡
- **寒热并见是厥阴最典型特征**
  - 上热：消渴、心中疼热
  - 中寒：饥而不欲食
  - 下寒：下利
- 中焦、上焦都冷掉了 → 肠胃没有消化能力 → 寄生虫寄生
- 消渴 = 上焦有热，被下面的寒顶上来
- 饥而不欲食 = 脾脏功能还在（知饥），但胃不好了（不能纳）
- **欲解时**：丑至卯上

### 厥阴寒热鉴别

| 表现 | 属性 | 病机 |
|------|------|------|
| 消渴 | 上热 | 热被寒顶上来 |
| 气上撞心 | 上热 | 热气往上冲 |
| 心中疼热 | 上热 | 胃中灼热 |
| 饥而不欲食 | 中寒 | 脾知饥，胃不纳 |
| 食则吐蛔 | 中寒 | 肠胃冷，蛔虫不安 |
| 下利 | 下寒 | 脾肾阳虚 |
| 手足厥逆 | 阳虚 | 阳气不达四末 |

### 代表方剂

| 方剂 | 适应症 |
|------|--------|
| **乌梅丸** | 厥阴主方——蛔厥、久利、肝虚补肝第一方 |
| **当归四逆汤** | 手足厥寒，脉细欲绝。治冻疮、疝气 |
| **干姜黄芩黄连人参汤** | 食入口即吐（寒格） |
| **白头翁汤** | 肝实热——下利便浓血、腥臭 |
| **吴茱萸汤** | 肝寒湿初起——干呕、吐涎沫、头痛 |

### 治肝三法（金匮核心——上工治未病）

> **「见肝之病，知肝传脾，当先实脾」**

| 治法 | 原则 | 经方 | 病机 |
|------|------|------|------|
| **补用酸** | 酸入肝，收敛补肝 | **乌梅丸** | 肝虚，久利，蛔虫 |
| **助用焦苦** | 苦温燥湿止呕 | **吴茱萸汤** | 胃中虚寒，干呕吐涎沫 |
| **益用甘味** | 甘味调脾胃 | **小建中汤** | 肝病及脾，防肝木克土 |

**肝实热**：下利便浓血、腥臭 → **白头翁汤**（寒凉药清热）

> **倪海厦**：乌梅丸是"苦温"药，不是苦寒——"温能化湿，只有温才能把湿化掉"
> 乌梅丸就是让你身体里面那棵树（肝）长得很好

### 厥热胜复（厥阴病动态判断）

> 厥阴病最复杂的特征：手足厥冷与发热**交替出现**

| 比重 | 判断 | 预后 |
|------|------|------|
| 厥多热少 | 病进 | 阳气渐衰，预后差 |
| 热多厥少 | 病退 | 阳气来复，预后好 |
| 厥热相等 | 病稳 | 正邪相持 |

|------|------|------|

| 人参 | 六两 | 补气 |
| 黄柏 | 六两 | 苦燥 |

**倪海厦经验**：
- **治肝第一方**：苦温化湿，让肝木生长环境良好
- **久利神方**：所有治利方无效时，靠乌梅丸
- **驱虫机理**：虫闻甘味来→遇辛辣往下逃→遇苦被泄出→生态环境改掉
- **服法**：晚上睡前吃，早上上厕所愉快。大人25粒，小儿15粒

```
IF 脉细数 + 心烦不得卧 + 舌红少苔
```

## 诊断公式八：合病/并病

### 合病与并病定义

- **合病**：两经或三经**同时**发病
- **并病**：一经未罢，又传入另一经（**先后**发病）

### 合病/并病速查表

| 合病类型 | 核心症状 | 方剂 |
|----------|----------|------|
| **太阳少阳合病** | 发热汗出恶风 + 口苦胁痛，脉浮弦 | **柴胡桂枝汤** |
| **太阳阳明合病（表寒里热俱实）** | 无汗恶寒身痛 + 口渴便秘，脉浮紧有力 | **大青龙汤** |
| **太阳阳明合病（表证轻里热重）** | 轻微恶寒 + 高热大汗口渴便秘 | **葛根芩连汤** |
| **太阳阳明合病（下利）** | 发热恶寒 + 下利 | **葛根汤** |
| **少阳阳明合病** | 寒热往来口苦 + 高热便秘，脉弦数有力 | **大柴胡汤** |
| **少阳太阴合病** | 往来寒热口苦 + 腹满便溏食不下，脉弦缓 | **柴胡桂枝干姜汤** |
| **太阳太阴并病** | 太阴里虚寒（腹满便溏不渴）+ 太阳表证（发热恶寒） | **桂枝人参汤** |
| **三阳合病** | 腹满身重 + 口不仁 + 面垢谵语遗尿 | **白虎汤**（独清阳明） |
| **太阳少阴两感** | 发热恶寒 + 脉沉微但欲寐 | **麻黄附子细辛汤** |
| **太阴少阴并病** | 腹满便溏 + 脉微细厥冷 | **附子理中汤** |
| **少阴厥阴并病** | 脉微细厥冷 + 寒热错杂 | **四逆汤合乌梅丸** |

### 治疗先后原则

```
合病（同时发病）→ 合方同治
并病（先后发病）→ 先治原发经，或标本同治
表里同病：
  里虚者 → 先温里后解表（如太阴并太阳先用桂枝人参汤）
  表里并重 → 表里同治（如大青龙汤）
三阳合病 → 独清阳明（白虎汤），阳明为三阳之里
```

## 传变规律

### 正传（由表入里）

```

太阳 → 少阳 → 太阴 → 少阴 → 厥阴
```

### 误治传变与急救方案

### 用药铁律

| 铁律 | 后果 |
|------|------|
| **有汗用麻黄** | 亡阳 |
| **无汗用桂枝** | 邪不解，郁而化热 |
| **少阳用汗法** | 谵语 |
| **少阳用下法** | 悸而惊 |
| **少阴用汗法** | 亡阳（危证！） |
| **表证误下** | 利不止/胁热痢/结胸/心下痞 |
| **厥阴误下** | 利不止 |
| **温针过度** | 津液丧失 |

### 误治急救方案

| 误治 | 急救方 |
|------|--------|
| 表证误下 → 利不止 | **理中汤**（温中止泻） |

## 真寒假热 / 真热假寒 鉴别（八维法）

### 真寒假热

| 项目 | 表现 |
|------|------|
| 面色 | 两颧色红，界限分明，红部鲜艳，不红部白中带青 |
| 口鼻气 | 呼出气不温，不急促，气不臭 |
| 舌形 | 舌干而质淡，或红而质润 |
| 脉象 | 脉虽浮数，按之则无力 |
| 胸腹 | 按之不蒸手，初按似热，久按不觉甚热 |
| **小便** | **清长，尿色淡白** |
| **口渴** | **渴不欲饮，或喜热饮** |
| **大便** | **便稀溏，无肛门灼热** |

### 真热假寒

| 项目 | 表现 |
|------|------|
| 面色 | 表虽冷，两目炯炯有神 |
| 口鼻气 | 呼出气必温，且急促 |
| 舌形 | 舌干而质燥，苔薄而根必厚 |
| 脉象 | 脉虽沉细，必兼数急 |
| 胸腹 | 四肢虽寒，胸腹必热，久按蒸蒸有热气 |
| **小便** | **短赤，尿色深黄** |
| **口渴** | **口渴喜冷饮，饮入即消** |
| **大便** | **便硬结，或热结旁流，肛门灼热** |

### 危重证候警示

| 证型 | 特征 | 急救方 |
|------|------|--------|
| **戴阳证** | 面红如妆（两颧鲜红如化妆） | **白通加猪胆汁汤** |
| **阴盛格阳** | 饮入即吐（拒热药） | **通脉四逆汤** |
| **脉微欲绝** | 阳气将脱 | **四逆汤 + 艾灸关元神阙** |

### 触诊要点

- **先触四肢，再触胸腹，最后触额部**
- **久按是关键**：初按似热、久按不热 → 真寒假热；初按似冷、久按蒸热 → 真热假寒

## 脉舌矛盾决策树

当脉象和舌象指向不同结论时，按以下规则判断：

| 矛盾情况 | 处理原则 |
|---------|---------|
| 脉浮但舌苔厚腻 | 里证为主，脉浮为假象 |
| 舌红但苔白 | 寒热错杂：舌红为脏热、苔白为腑寒（厥阴特征） |
| 脉数但舌淡 | 真寒假热，**以舌为准** |
| 脉沉但舌红苔黄 | 真热假寒，热深厥深 |
| 脉弦但舌淡苔白 | 少阳兼太阴虚（柴胡桂枝干姜汤证） |

**核心原则**：脉舌矛盾时，舌象比脉象更可靠——舌象反映脏腑本质，脉象受干扰因素多。

## 太阴与少阴交界判断

当太阴病发展到严重阶段，可能出现少阴表现，需判断是否已传入少阴：

| 鉴别点 | 太阴阶段 | 已传少阴 |
|--------|----------|----------|
| 脉象 | 浮缓或沉迟 | 沉微 |
| 精神 | 倦怠但神清 | 但欲寐（萎靡） |
| 口渴 | 不渴 | 渴（引水自救） |
| 小便 | 正常或略清 | 清长色白 |
| 四肢 | 可有不温 | 逆冷 |

**判断口诀**：太阴日久及肾，脉由沉迟转沉微，精神由倦怠转萎靡，当从少阴论治。

## 七步走辨证思维模式

```
第一步：定表里 ─→ 病在表（太阳）还是里（阳明/三阴）还是半表半里（少阳）？
    │
第二步：分阴阳 ─→ 脉浮/大/弦 → 阳证；脉沉/微/细 → 阴证
    │
第三步：辨寒热 ─→ 有汗vs无汗？恶寒vs恶热？真寒假热vs真热假寒？
    │
第四步：判传变 ─→ 当前证候可能的走向？是否已传经？
    │
第五步：审体质 ─→ 阴虚/阳虚/痰湿/血瘀？对方剂有何影响？
    │
第六步：选方剂 ─→ 方证对应，主次分明
    │
第七步：精细加减 ─→ 根据兼证、体质、轻重调整药物和剂量
```

**初学者掌握前三步即可应对70%的常见病**，熟练后再逐步补充后四步。

## 倪海厦临床心法

1. **"观其脉证，知犯何逆，随证治之"**——辨证论治的总纲
2. **"百病风之始"**——所有病刚开始都是风引起的
3. **"阳明无死证"**——病进入阳明就停住，不会再传
4. **"有表证时绝对不可攻里"**——先解表再攻里
5. **"但见一证便是，不必悉具"**——少阳证见一个症状就可用小柴胡汤
6. **"阴不足不用滋阴，要壮阳"**——阳一壮就把阴拉起来了
7. **"药就是药，身体健康时才吃补药"**——治病不用补药
8. **"保持平常心，不要吃西药"**——病进来了也只能在表

### 补充心法（测试验证后增加）

9. **"有汗不可用麻黄，无汗不可用桂枝"**——太阳病用药铁律
10. **"少阳三禁：禁汗、禁吐、禁下"**——只能和解
11. **"少阴病绝对不可发汗"**——发汗会亡阳
12. **"里气乃表气之本"**——太阴并太阳，先温里后解表
13. **"脉舌矛盾时，以舌为准"**——舌象比脉象更可靠
14. **"厥热胜复看比重"**——厥多热少病进，热多厥少病退

### 金匮心法（补充）

15. **"病痰饮者当以温药和之"**——痰饮病总治则
16. **"同症同治，不受病名限制"**——中医不立病名
17. **"上工治未病"**——有症状就动手，不等病名确立
18. **"见肝之病，知肝传脾，当先实脾"**——五行传变治未病
19. **"补用酸、助用焦苦、益用甘味"**——治肝三法
20. **"经方是唯一最高指导原则"**——倪海厦对经方的定位
