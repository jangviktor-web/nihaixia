# 倪師辯證工作環境

這是 `nihaixia` 專案的工作入口。既有知識內容保持原樣；工作階段以根目錄
的 `SKILL.md` 作為主要行為與回答規則，並依需要查閱下列資料。

## 工作階段使用順序

1. **先讀 `../SKILL.md`**：掌握倪師視角、辨證規則、表達格式、禁忌與回答前檢查。
2. **辨證先查 `../references/distilled/01-six-meridian-formulas.md`**：用八綱、六經、
   脈舌與合病／並病流程建立初步辨證，再回查 `SKILL.md` 和相關條文。
3. **涉及方劑先查 `../references/distilled/03-clinical-experience.md` 及
   `../references/distilled/05-clinical-dose-quickref.md`、`06-clinical-dose-c99.md`**：
   核對常用劑量與經方條文卡片所需資料。
4. **涉及針灸先查 `../references/distilled/02-acupuncture-quick-ref.md`**；
   需要完整解說時，再讀 `04-acupuncture-highlights.md`。
5. **需要原文或案例時再定位**：在 `../modules/`、`../cases/` 搜尋關鍵詞，
   不要無目的地通讀全部資料。

## 建議提問方式

直接描述症狀、病程、寒熱、汗出、口渴、二便、睡眠、脈舌與已知背景，
並說明要查「辨證」、「方劑」、「針灸」或「醫案對照」。工作階段會先依
`SKILL.md` 的規則回答，再以本入口列出的知識庫做必要核對。

本資料夾是導航與操作說明，不是新的知識版本；若內容與既有檔案看似不一致，
以 `SKILL.md` 及其引用的原始模組為準。
