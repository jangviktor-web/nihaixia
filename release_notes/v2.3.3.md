# v2.3.3 (2026-11-27) — 出处纪律与可考据性

**核心升级**：把「回答能不能被用户逐条核验」变成硬约束。新增出处纪律、溯源标记、问答纪律三段；检索器补否定词/方位词豁免；加出处审计函数与考据陷阱判据。

**目标不是让回答更长，而是让每个条文号、每个方证归属都能被宋本和讲稿原文对上。**

---

## 一、出处纪律（SKILL.md 硬约束段）

修复痛点：模型把《温病条辨》的「白虎四大症」当成《伤寒论》白虎汤证背书——「正确的方剂 + 错误的出处」，旧硬约束无一条能拦。

- 🔴 条文号、出处**只取检索返回的 `title`**；检索没返回就写「讲稿未覆盖此条」，不得凭记忆补「第 N 条」
- 🔴 方证归属与讲稿一致：讲稿只讲「大汗出、大烦渴、脉洪大」就只写这三个，不得拿后世著作的四症背书；引后世著作必须显式标书名
- 🔴 【方剂库摘要】的「四大证」等说法是本地整理、非倪师原话，不得当《伤寒论》条文引
- 🔴 诱导式提问（「是不是 X 方证？」）先答讲稿里 X 的条件，再答符合与否

## 二、溯源标记

- 行内写 `〔伤寒论讲稿·九六〕` / `〔金匮要略讲稿·呕而发热〕`，医案写「医案 #序号」，不另起注脚
- 明确区分「面向用户的溯源」与「内部检索线索」——`modules/XX`、路径、行号、（源XXXX）永不输出

## 三、问答纪律（对齐 App persona）

- 症状提问固定五步走：归纳主症 → 定病位 → 方证名 + 首选方 → 鉴别相邻方证 → 引医案
- 针灸四步答：辨证定经 → 取穴 → 手法 → 禁忌
- 穴位只用检索块给出的；无本地统计不凭空报数；无医案片段不虚构病案
- 同批：篇幅抑制三条（禁整串罗列方名、临床行不补全、不主动延展）

## 四、检索器：否定词与方位词豁免

- **背景**：自由率过滤对口语方位/身体词系统性偏杀，「无汗」「左边」「肚子」这类核心鉴别症状召回不到
- **改动**：`EXEMPT_TERMS` 进 priority 档（tier=0 天然豁免自由率），只取提问中实际出现的词；**未改过滤层**
- **效果**：`test_holdout.py` 12/13 → **13/13**；`test_differential.py` 42/42 不变

## 五、出处审计函数

- 新增 `unverified_formulas(answer, r)`，挑出回答里无检索依据的方名（支撑面＝命中方剂清单 ∪ 医案用方 ∪ 讲义片段正文）
- 只标注、不改写、不拦截；天花板＝只认方剂库已有方名，漏报但不误报

## 六、考据陷阱判据

- 新增 `test_source_discipline.py`，按句判「后世概念是否被归给《伤寒论》」，与检索解耦，含题 4 重建用例
- 修订：加否定式与反问豁免（`不是／并非／不可当／哪一条`）+ 标点归一化，消除真实正确回答被误报（首轮在真实回答上出现 2 处假阳性）
- 判据 14/14

## 七、两条硬规则补强

- **剂量核对**：检索片段按 520 字窗口截断，方剂剂量一律视为不完整，**必须回 `modules/` 搜方名取原方行逐字核对**，不得因片段断在方名处就判「未列全」
- **编号统一**：索引 `title` 前缀＝**宋本编号**，面向用户一律用它；`modules/` 的「条文N」是倪师讲课编号（与宋本整体错位，如条文80≈宋本74），**只用于内部检索定位，不得写进回答**
